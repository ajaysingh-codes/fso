# Part 1 — React Foundations

This part of the Full Stack Open course introduced the building blocks of modern React development.

## What I learned
- How to build user interfaces with React components and JSX
- How props and state work together to make apps interactive
- How to handle user events such as clicks and button presses
- How to render content conditionally and from lists
- How to structure small apps like a course info page, a feedback app, and an anecdotes app
